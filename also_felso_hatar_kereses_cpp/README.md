# Alsó- és felső határ keresés megvalósítása C++-ban

Növekvő módon rendezett tömbben keressük az első olyan elem indexét, amely elem nem kisebb, illetve nagyobb egy előre megadott értéknél.

Az implementált kódhoz tartozó magyarázat a [blogomon](https://programozas.sergyan.hu/algorithms/lowerandupperbound/) olvasható.
